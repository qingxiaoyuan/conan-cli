Conan CLI UI 设计稿

工作台三件套

按需求改过：不再做包市场。用户面对的是初始化、扫描 Qt/编译器、按操作系统和架构找制品、设置页（全局 Nexus 登录 + 项目工具链）、发布填表。VS Code 与终端字段对齐，动作都落到命令。

平台 = Windows / Linux / 麒麟 × x86 / x64 / ARM

编译器、Qt 是项目设置，查找时与平台组合

登录只在设置里录；缺二进制只提示，不在本机编译

VS Code 侧边栏

项目状态、平台、扫描结果、快捷下载/发布/设置。完整表单进控制台。

VS Code 控制台

可点击：概览、依赖分析、下载、发布表单、全局/项目设置、诊断。

终端 TUI

概览、设置（终端也能改）、依赖分析、发布表单。键位驱动。
